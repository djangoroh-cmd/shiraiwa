# 卓球ゲーム (Table Tennis)

ブラウザで遊べるシンプルな卓球（Pongスタイル）ゲームです。HTML5 Canvas と素の JavaScript のみで作られており、ビルド不要で動作します。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーを立てて `http://localhost:<port>/` にアクセスしてください。

```sh
python3 -m http.server 8000
```

- **操作**: ↑ / ↓ キー、W / S キー、またはマウスの上下移動でパドルを操作
- **開始 / 一時停止**: Space キー、または画面のボタン
- **一時停止**: P キー
- **難易度**: スタート前に かんたん / ふつう / むずかしい を選択可能
- 先に5点取った方が勝利です

## ファイル構成

- `index.html` — ページ構造
- `style.css` — 見た目のスタイル
- `game.js` — ゲームロジック（物理演算、CPU AI、スコア管理）
